# :cd: tm-player

A terminal-based music player built with Rust and the Ratatui framework.

## :rocket: Features

- Browse and play local music files.
- Create and manage playlists.

## :wrench: Installation

1. Ensure you have Rust installed. If not, install it from [rustup.rs](https://rustup.rs/).
2. Clone this repository:
```bash
git clone
```
3. Navigate to the project directory:
```bash 
cd tm-player
```
4. Build the project:
```bash 
cargo build --release
```
5. Run the application:
```bash 
cargo run --release
```
